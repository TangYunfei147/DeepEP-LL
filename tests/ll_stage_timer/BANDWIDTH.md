# 事件计时的字节与有效带宽

字节来自5类独立计数：local、intrahost_first、intrahost_forward、interhost_first、interhost_forward。每类bytes/operations包含read_bytes/read_operations子集，不重复相加。

dispatch首发及relay按实际packet字节计一次；combine direct返回按packet字节，partial gather按2H读取字节，partial归约回传按packet字节计一次。本卡移交不进跨卡带宽；prepare暂存和本地消费不重复统计；独立count/ready控制通信未计入，包内header/tail/flags已包含。

EP16逐rank逐轮：intrahost_total_bytes=首发+转发；duration_us=max各核kernel事件跨度换算；effective_GBps=bytes/(duration_us*1000)。先逐轮相除再统计。该指标是发起端读+写数据搬运吞吐，含计算和等待成本，不是纯TX或物理线速。

读取/转发比例从当次计数计算，不从固定hidden推测。非EP16、不知道频率、跳过通信标记或零时长不报告有效带宽；真实零计数与错误数据分开。所有阶段时长直接从schema4逐次事件计算。PIPE_ALL会改变分母，诊断模式不作未插桩基线。
