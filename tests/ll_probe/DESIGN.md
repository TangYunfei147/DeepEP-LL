# LL 发送量带宽与固定开销实验

目标单卡与 A5_241 相同，互联不同。A5_241 只验证正确性与可运行性；目标互联测量由用户执行。所有实验文件相对工程根定位，A5验证遵守授权写入边界。

## 发送量扫描

独立 kernel 沿用 dispatch SendPacket 的 AscendC DataCopy(peer GM, UB) 原语。提供空 kernel、仅分配/初始化 UB、预置 UB 发送、GM→UB→GM 四种模式。前三者的差值只用于归因，不直接当作当前 LL 的固定开销。

发送量轴指每个发送 rank 每次 kernel 调用发送的字节数。建议 32B 至 64MiB 的对数扫描，在 LL tokenStride 与实际负载附近加密。另独立扫描并发 AIV 数 1/2/4/8/16/32 和 lane 数 1/2/4；保持 chunk 固定后再扫描 chunk。大数据量使用不重叠的目标地址，避免测成反复覆盖同一个 cache line。

测试拓扑分别记录本卡、单向 peer、双向 peer、用户指定多 peer；禁止从双卡结果推断目标整机互联。对端 GM 必须由 Host 正确导入/映射，不能将别的进程的裸指针当作有效地址。发送完成后由对端校验完整输出，不能只校验发送方本地映射。

预置 UB 模式输出 0x5a；完整搬运模式输入使用确定性非恒定字节序列，接收端逐字节验证。每次运行先进行小/尾块/多核/多 lane 校验，校验后预热，再测量。核间写入地址不重叠，所有长度为 32B 的倍数，chunk≤32KiB、lane≤4。原始样本、退出状态和实际配置必须保存。

kernel 时间优先使用 profiler 的明确 kernel task，完整调用使用 Host 墙钟另报。单向有效 GB/s = payload_bytes / (kernel_us * 1000)。达成率只在用户提供匹配方向、拓扑、单位的参考峰值后计算；双向总带宽须使用双向总字节数，不能与单向峰值混用。重复发送 iterations>1 另列为摊销实验，不覆盖单次发送结果。

## 当前 LL 固定开销

当前 LL 支持 EP16/32/64/128、B>0，不能运行零 token LL 并声称得到当前实现的固定开销。由用户在合法拓扑上执行 B=1/2/4/8/16/32/64/96/128/256（各 shape 以 native preflight 为准），固定 H/K/E/dtype/路由，分别保留 dispatch 与 combine 原始 kernel 样本。

先以多发送量样本拟合 t=alpha+beta*wire_bytes，输出 alpha、残差及拟合区间；alpha 明确标记为经验截距估计。检查小 B 核占用、去重/relay 路径、lane 数或路由变化引起的分段；不能将不同分段强行拟合，也不能把负截距裁剪为 0。

第二阶段添加可选 LL 阶段插桩，定位计数协议、magic 轮转、路由/打包、发送与接收等待、归约等成本。保持生产路径不插桩的结果作为基线；插桩影响计时，阶段重叠时不能相加得到整体时间。Host 初始化/分配/同步另测，不能混入 kernel 固定成本。
